# Supabase Auth 2FA Gig

Title: Supabase Auth TOTP 2FA — example components and RLS policy templates

What it does
- Provides example React components for MfaSetup and MfaVerify and a small AuthGuard to require AAL2.
- Includes an SQL template for creating a table with user_id and RLS policies.

Setup
- Copy the components into your app and wire to Supabase Auth client.
- To enable TOTP in Supabase, follow Supabase docs and enable TOTP in project auth settings.
